== Armagetron Advanced


https://www.armagetronad.org/

https://sourceforge.net/projects/armagetronad/

https://gitlab.com/armagetronad/armagetronad

Armagetron is a multiplayer game in 3d that attempts to emulate and expand on the lightcycle sequence from the movie Tron. 

=== build

[source, shell]
----
./bootstrap.sh
./configure
make
sudo make install
----
